[Feature] Kiro CLI style transcript, approval bottom sheet, auto hand-back

[Root Cause]
1. After reopening the app, detach no longer offered hand-back: the origin
   pane was only returned by session.attach and lost on app restart.
2. Closing the app left taken-over sessions attached forever.
3. The bubble chat view started at the top of the history and hid tool
   details; it should read like the Kiro CLI, with a phone-friendly
   approval UI.

[Solution]
1. attached.list returns originPane; the app restores it on resync.
2. Auto hand-back: the host counts WebSocket clients; when none has been
   connected for AGENTDOCK_HANDBACK_MINUTES (default 10, 0 disables) a
   30 s loop detaches idle sessions (no running turn, no pending
   approval) that came from a tmux pane and resumes them there.
   session.closed carries reason "auto_handback".
3. Chat view: dark monospace transcript like the Kiro CLI. "> prompt"
   rows separated per turn, replies rendered as Markdown
   (flutter_markdown_plus, selectable), thoughts shown by default,
   "● Shell <command>" tool rows with live output (last 12 lines, tap to
   expand), status line (思考中 / 回复中 / 执行工具中 / 等待审批 / 空闲).
   Follows new output, pauses when the user scrolls up, "back to bottom"
   button; opens at the latest output.
4. Approvals open as a bottom sheet with large full-width buttons and a
   scrollable parameter box; it closes itself once answered anywhere, is
   not re-opened after being dismissed, and the transcript keeps a one
   line record that reopens it.

[Test]
