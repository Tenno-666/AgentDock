## 4. push 认证

二选一，GitHub 不接受登录密码。

### 4.1 Fine-grained Personal Access Token

1. 打开 https://github.com/settings/personal-access-tokens/new
   （头像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token）
2. Token name 随意；Expiration 选有效期
3. Repository access 选 **Only select repositories**，勾选 `Tenno-666/AgentDock`
4. Permissions → Repositories 标签 → **Add permissions** → 搜索框输入权限名 **Contents** → 选中后把 Access 改为 **Read and write**
   - Metadata（Required，只读）会自动加上
   - Account 标签不用加任何权限
   - 注意：搜索框搜的是权限名称，搜 "Read and write" 会显示 No items available
5. Generate token，立即复制（页面关闭后不再显示）
6. `git push` 时 Username 填 `Tenno-666`，Password 粘贴 Token

Token 等同于仓库写权限密码：不要发到 AI 对话里，也不要写进仓库。可以让 git 在内存里记住 1 小时：

```bash
git config credential.helper 'cache --timeout=3600'
```

Token 过期后按上面的步骤重新生成即可，旧 Token 可在 https://github.com/settings/personal-access-tokens 里 Revoke。

### 4.2 SSH 公钥

```bash
cat ~/.ssh/id_rsa.pub    # 复制输出，添加到 GitHub → Settings → SSH and GPG keys → New SSH key
git remote set-url origin git@github.com:Tenno-666/AgentDock.git
ssh -T git@github.com    # 显示 "Hi Tenno-666!" 即成功
```
